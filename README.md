# Утро 7

Личная утренняя 7-минутная тренировка: 12 упражнений, встроенная синтезированная музыка, календарь привычки, серии дней. Без аккаунтов и серверного сбора данных.

## Открыть

https://dmitriy-bondarev.github.io/utro7/

## Установить на iPhone

Открой адрес в **Safari** → **Поделиться** → **На экран «Домой»** → **Добавить**.

## Особенности

- Прогресс хранится локально в Safari/PWA на устройстве (localStorage), синхронизации нет.
- При уходе приложения в фон тренировка ставится на паузу.
- Закрытие до завершения 7 минут не засчитывается.
- Музыка — оригинальная электронная мелодия, создаваемая WebAudio, без внешних файлов.
- Историю можно сохранить и восстановить JSON-файлом в разделе «Привычка».
- Приложение рассчитано на работу офлайн после первого успешного открытия.

## Лицензирование

Исходный код опубликован для личного использования; приложение не аффилировано с Seven.
