# Утро 7

Личная утренняя 7-минутная тренировка: 12 упражнений с собственной циклической SVG-анимацией, предварительный просмотр всех движений, встроенная синтезированная музыка, календарь привычки, серии дней. Без аккаунтов и серверного сбора данных.

## Открыть

https://dmitriy-bondarev.github.io/utro7/

## Установить на iPhone

Открой адрес в **Safari** → **Поделиться** → **На экран «Домой»** → **Добавить**.

## Что изменилось в версии 0.3

- Динамические демонстрации движений для всех 12 упражнений, включая отжимания.
- Предпросмотр движений до запуска тренировки.
- Анимация останавливается при паузе, а на перерывах показывает предстоящее упражнение.

## Особенности

- Прогресс хранится локально в Safari/PWA на устройстве (localStorage), синхронизации нет.
- При уходе приложения в фон тренировка ставится на паузу.
- Закрытие до завершения 7 минут не засчитывается.
- Музыка — оригинальная электронная мелодия, создаваемая WebAudio, без внешних файлов.
- Историю можно сохранить и восстановить JSON-файлом в разделе «Привычка».
- Приложение рассчитано на работу офлайн после первого успешного открытия.

## Лицензирование

Исходный код опубликован для личного использования; приложение не аффилировано с Seven.

## Версия 0.4 — каталог и конструктор

- Каталог: 12 упражнений с анимированными демонстрациями, категориями и поиском.
- Четыре готовых комплекса: «Утро 7», «Мягкий старт», «Сила и корпус», «Разминка и гибкость».
- Конструктор: произвольный порядок, повторы упражнения, время движения и отдыха, сохранение, редактирование, удаление и запуск.
- История занятий и пользовательские комплексы сохраняются локально. Экспорт истории включает пользовательские комплексы.
- Все анимации оригинальные схематичные иллюстрации, не 3D-видео.
