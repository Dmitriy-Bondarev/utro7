- Прогресс хранится локально в Safari/PWA на устройстве (localStorage), синхронизации нет.

- Закрытие до завершения 7 минут не засчитывается.
- Музыка — оригинальная электронная мелодия, создаваемая WebAudio, без внешних файлов.
- Историю можно сохранить и восстановить JSON-файлом в разделе «Привычка».
- Приложение рассчитано на работу офлайн после первого успешного открытия.
