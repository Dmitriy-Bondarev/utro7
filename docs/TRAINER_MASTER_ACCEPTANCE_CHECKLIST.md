## Как проводить приёмку

1. Указать версию модели, рендер-движок, дату, ссылку на master source и идентификаторы ассетов.
2. Для каждого пункта отметить PASS / REWORK / N/A и дать ссылку на изображение, Blender-исходник или проверку. N/A допустимо только с обоснованием.
3. Визуальная приёмка T1 **до** тестирования T2–T3. Не показывать упражнения, пока мастер-персонаж не принят.
4. При любой критической проблеме отметить общий статус REWORK и не продолжать на следующий gate.
5. **Только пользователь** устанавливает итог ACCEPTED для визуального блока.
