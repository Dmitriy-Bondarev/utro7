## 3. Измеримый результат исправления

Параметры проверены на Blender-сценах, а не по впечатлению. Источники: [rejected rig audit](rejected_pushup_rig_audit.json) и [candidate rig audit](candidate_pushup_rig_audit.json). Численные пороги — **эвристики геометрического QA**, не медицинские нормы.

| Показатель | Старая сцена v2 | Исправленная v3 |
|---|---:|---:|
| Угол локтей в верхней позе | **86,5°** | **157°** |
| Разница лево/право по траектории локтей (Y) | **0,322 м** | **0,000 м** |
| Несимметричность по X | **0,272 м** | **0,000 м** |
| Минимальная высота носков над полом | **−0,128 м** | **+0,017 м** |
| Контакт запястья с IK-целью | 0 м | 0 м |
| Число не пройденных геометрических проверок | **≥4** | **0 из 12** |

**Инженерное исправление:** положение rig по высоте `Z=0.205` вместо `0.060`; обе стороны локтевых pole angles `-π/2` вместо `0`. Эти изменения выбраны перебором параметров `tools/blender/explore_pushup_ik.py`, не подгонкой видеоэффекта. При этом остаётся обязательное ручное ревью формы движения, контактов и художественного качества.

## 4. Факты и допущения

- Реалистичная **сетка человека MPFB + спортивная одежда** используется вместо геометрического человечка в приёмочном прототипе; она **ещё не заменяет** аватара внутри основного приложения.
- Позиции рук в статических кадрах технически симметричны, **но это не гарантирует профессионально правильного отжимания**. Тренер должен проверить оси плеч/локтей/кистей, расстояние между стопами, поясницу и амплитуду в ракурсах A/B/C.
- В старых файлах остаются 7 экспериментальных MP4, но новый реестр запрещает их использовать как `approved` демонстрации.
- Текущие SVG остальных упражнений также не прошли профессиональную приёмку. UI явно отмечает их как схемы, а не проверенную технику.
- 3D-расширение до остальных 23 карточек ТЗ **не запускалось**.

## 6. Тестирование и воспроизводимость

На Mac:

```bash
python3 tools/dev/build_motion_policy.py --check
python3 tools/dev/validate_g1.py
blender -b -t 4 assets/motion/quality-v3/trainer-female-pushup-static-v3.blend -P tools/blender/audit_pushup_rig.py
PUPPETEER_PATH=/path/to/puppeteer node tests/motion-smoke.cjs
PUPPETEER_PATH=/path/to/puppeteer node tests/pose-review-smoke.cjs
PUPPETEER_PATH=/path/to/puppeteer node tests/smoke.cjs
```

Публикационный статус видео хранится **только** в `content/motion/registry.json`. Ручная подмена на `approved` без ревью, даты, контрольной суммы и подтверждения device-QA блокируется сборщиком. Сгенерированный JS не редактируется вручную.
