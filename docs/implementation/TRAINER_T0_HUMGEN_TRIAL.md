## Исходник и установка

Переданная пользователем email-ссылка через сервис Brevo/Sendinblue приводит на официальный сайт https://humgen3d.com/trial (HTTP 302). Ссылка сама является страницей установки, а не ZIP. Персональный трекинговый адрес не сохранён в GitHub.

С официальной страницы загружены **два файла**:

| Файл | Размер (байт) | SHA256 |
|---|---:|---|
| HumGen3D_v4_0_29.zip | 5 060 368 | 17c7493b82b32d0d43c1023e4673c217d1cfca00c0145b4174a4832fedc9c4bb |
| HG_Trial_Content.hgpack | 269 224 756 | b38e84b50c603dc4f5d33dde9cf5fc6ce3114fc58f54447169f87cc4b1849505 |

Оба архива прошли ZIP integrity check; пути безопасны. Trial содержит около 330 МБ распакованных данных. Загрузки с Mac через системный HTTP(S)-прокси 127.0.0.1:2080 прерывались после 20–26 КБ. Прямая связь с **официальным сервером только для этих двух файлов** прошла успешно; настройки VPN/системного прокси не менялись.

Установка выполнена на MacBook Pro M5 Pro / Blender 5.3.0 с использованием официального Blender add-on installer и vendor content-pack operator. Аддон **HumGen3D 4.0.29 включён**, 1173 файлов контента установлено в приватную папку. После настройки каталога новый запуск Blender не выдаёт ошибок; vendor preferences показывают is_trial=True.

## Жёсткое ограничение trial

По https://humgen3d.com/trial разблокирован **только мужской стартовый пресет Caucasian 1**. Женские базовые модели закрыты, функция Process для экспорта также ограничена. Не обходить блокировку и не выдавать мужского персонажа за женскую мастер-модель.

Официальный прайс https://humgen3d.com/pricing: **Commercial $128**, покупка не согласована и не совершалась. В https://humgen3d.com/docs/faq/license-faq уточняется: для коммерческих рендеров и программ нужна коммерческая лицензия; исходные модели/текстуры не разрешено свободно распространять. Страница pricing содержит противоречивое описание прав Personal, поэтому при покупке необходимо проверить полную лицензию.

## Quality gates

- **PASS:** официальный источник, загрузки/архивы, установка Blender 5.3, наличие trial-контента, создание одной разрешённой 3D-модели, проверяемый rig.
- **BLOCKED:** создание одной качественной **женской** модели из trial; нет исходника женского тренера.
- **NOT STARTED:** T1 визуальная приёмка женского образа, T2 rig женского тренера, T3 позы, T4 мастер-ассет ACCEPTED.
- **НЕ ДЕЛАЛИ:** новых упражнений, включения видео в PWA, покупки лицензии.
